# StudyBridge - Student Support Website

IS 1106 Foundations of Web Technologies, Semester 1 Group Project.

## Files
- `index.html` - home page
- `study-tips.html` - tips, disruption plan table, FAQ accordion
- `resources.html` - searchable and filterable resource cards
- `planner.html` - study-hours calculator, GPA calculator, timetable table
- `contact.html` - validated contact form (nothing is stored or sent)
- `style.css` - all styling (Flexbox, Grid, media queries)
- `script.js` - all interactivity

## JavaScript features
1. Mobile menu toggle
2. FAQ expand/collapse
3. Resource search and category filter
4. Study-hours and GPA calculators
5. Contact form validation

## Hosting (free static options)
GitHub Pages, Netlify or Cloudflare Pages. Upload the whole folder, then test the live URL on desktop and phone.
